# IEEE paper — build & self-score loop

**Paper:** *Real-Data Machine Learning for Rural Telemedicine Triage and Outbreak Surveillance*
**Venue:** Nexathon II Paper Presentation (IEEE format, AIKTC, 9 Oct 2026)

## Build (requires MiKTeX)

```bat
paper\build.bat
```

Pipeline: `make_numbers.py` (regenerates `numbers.tex` from
`ds/models/paper/paper_numbers.json` — numbers are never hand-typed) →
`pdflatex` → `bibtex` → `pdflatex` ×2 → `paper/main.pdf`.

## Audit (machine-checkable rubric criteria)

```bat
python paper\audit.py           :: numbers / cites / originality / honesty / format
python paper\audit.py --json
```

Exit code 0 = all automated criteria pass.

## Self-score loop

Each iteration writes `paper/selfscore_vN.md`: rubric scores (0–5 per
criterion, weighted to 100), pass-bar check (≥85 and every critical ≥4), and
the gap list that drives the next iteration.

| File | Purpose |
|---|---|
| `main.tex` | IEEEtran conference draft (placeholder byline) |
| `numbers.tex` | GENERATED — macro-per-number from `paper_numbers.json` |
| `make_numbers.py` | JSON → `numbers.tex` generator (+ `--check`) |
| `build.bat` | deterministic build (MiKTeX on PATH) |
| `audit.py` | automated audits (5 sections) |
| `selfscore_vN.md` | per-iteration scorecard |
| `main.pdf` | committed deliverable (hard copy) |

Tables/figures are committed artifacts in `ds/models/paper/` (generated by
`ds/paper_figures.py` / `ds/paper_tables.py` — never hand-edited).
