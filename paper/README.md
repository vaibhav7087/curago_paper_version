# IEEE paper — build, self-score loop, format exports

**Paper:** *Real-Data Machine Learning for Telemedicine Triage and Outbreak Surveillance*
**Venue:** Nexathon II Paper Presentation (IEEE format, AIKTC, 9 Oct 2026)

## Build (requires MiKTeX)

```bat
paper\build.bat
```

Pipeline: `make_numbers.py` (regenerates `numbers.tex` from
`ds/models/paper/paper_numbers.json` — numbers are never hand-typed) →
`pdflatex` → `bibtex` → `pdflatex` ×2 → `paper/main.pdf`.

## Deliverable formats

| File | Format | Generator | Notes |
|---|---|---|---|
| `main.tex` (+ `numbers.tex`, `ds/models/paper/*.tex`) | LaTeX | hand-authored / `make_numbers.py` | IEEEtran `[conference]`, source of truth |
| `main.pdf` | PDF | `build.bat` | layout-faithful, 6 pages, committed |
| `main.md` | Markdown | `export_md.py` | prose/tables/refs/figures, numbers macro-injected |
| `main.docx` | Word (DOCX) | `export_docx.py` | editable single-column render from `main.md` |
| `main.bbl` | BibTeX output | `build.bat` | generated per build (gitignored) |

```bat
python paper\export_md.py            :: writes main.md (fail-closed on unknown LaTeX)
python paper\export_docx.py          :: writes main.docx (validates headings/tables/images)
python paper\export_md.py --check    :: verify main.md current
python paper\export_docx.py --check  :: verify main.docx valid
```

Legacy binary `.doc` is not emitted (no Word on the build machine); DOCX is
the editable submission format.

## Audit (machine-checkable rubric criteria)

```bat
python paper\audit.py           :: numbers / cites / originality / honesty / format
python paper\audit.py --json
```

Exit code 0 = all automated criteria pass.

## Self-score loop

Each iteration writes `paper/selfscore_vN.md`: rubric scores (0–5 per
criterion, weighted to 100), pass-bar check (≥85 and every critical ≥4), and
the gap list that drives the next iteration.

| File | Purpose |
|---|---|
| `main.tex` | IEEEtran conference draft (placeholder byline) |
| `numbers.tex` | GENERATED — macro-per-number from `paper_numbers.json` |
| `make_numbers.py` | JSON → `numbers.tex` generator (+ `--check`) |
| `build.bat` | deterministic build (MiKTeX on PATH) |
| `audit.py` | automated audits (5 sections) |
| `export_md.py` | `main.tex` → `main.md` converter (+ `--check`) |
| `export_docx.py` | `main.md` → `main.docx` converter (+ `--check`) |
| `selfscore_vN.md` | per-iteration scorecard (v1 88 → v2 92 → v3 98 → v4 98, review T1–T3) |
| `main.pdf` / `main.md` / `main.docx` | committed deliverables |

Tables/figures are committed artifacts in `ds/models/paper/` (generated by
`ds/paper_figures.py` / `ds/paper_tables.py` — never hand-edited).
